# 1.0.0 · 内置语音、后台恢复与补丁基础版

修复网络切换、亮屏或休眠恢复时，SnowLuma控制台短暂不可达导致正常QQ连接被断开、正在生成的回复被取消的问题。优先核验已有消息通道；真实断开后独立重连、重新检查身份与在线状态；控制台恢复单独限时、避免并发重复修复。同账号恢复保留上下文和群聊续聊；账号或主人切换仍清除旧身份上下文。发送结果不确定时继续保留不重发保护。

语音新增随包内置的 Kokoro v1.1 中文模型与四种中文女声，在“能力→语音”点“一键使用内置中文女声”即可启用。无需额外Key、参考录音或电脑声音服务；每轮仍由聊天模型结合上下文选择文字或语音，不另加一次形式判断调用。完整语句合成后拼为一条，分段必须全部成功；失败回退文字。ZipVoice参考克隆、肥鱼后端、系统TTS、Azure和QQ群音色保留，已有选择不会被更新强制覆盖。

本版是完整基础包。后续1.0.x发布差分补丁，应用本地重建完整APK、检查哈希和原签名后交系统安装。1.1等大更新再发完整包。基础整包保留供新用户安装，详见[补丁说明](PATCH-UPDATES.md)。

同时包含此前开发版的252个离线基础依赖；API、角色、独立账号和上下文方案卡片；视频每秒1/2/4帧可选；每轮按真实状态提示模型语音能力。高采样增加总请求及Token，单次预算估算不等于整片精确用量。首次空白初始化仍需解包和配置，测试平板约11分钟；QQ官方登录和网络由用户完成。

安装：Android11+、ARM64，约1.06GB，内部版本号10000，沿用原签名；直接覆盖保留配置，无需卸载。较旧更新器不能使用补丁，先安装此完整包。建议预留数GB空间，更新阶段另需完整安装包的临时空间。

验证：207项Node回归、10项Android框架检查、Python差分重建与损坏拒绝测试通过；Android实际验证8种无效补丁拒绝与清理。完整新包在平板从旧安装包重建，SHA256逐字节一致，原签名检查及覆盖安装通过。模型和配置未用于QQ发信或付费调用。

小米2410CRP4CC实测新语音：首次12字约11.3秒、23字中英混读约6.8秒、103字约32.4秒（含转码），长句生成约30秒音频；独立离线转写检测到完整末尾。耗时随设备、冷启动和文本变化，不承诺达到真人听感；Kokoro不是肥鱼声线，语气主要来自口语及轻微语速调整，不假称独立娇羞模型。

平板保留数据安装1.0.0，九项环境检查通过，QQ登录网页HTTP200，实际身份与在线核验通过。网络通知期间保留正在生成的回复、控制台不可用时消息独立重连以隔离模拟验证；没有发送QQ测试消息或消耗付费模型。厂商强行冻结/停止应用仍需允许后台运行，代码不能保证强制停止后永久在线。锁屏下未进行新版界面人工观感验收。
