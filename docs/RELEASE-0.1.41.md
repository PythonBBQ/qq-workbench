# 0.1.41：本机轻量语音与多号恢复

新增 ZipVoice-Distill INT8 + sherpa-onnx Android 原生 CPU 语音。模型随包内置，首次自动解压校验，无需语音 API Key。聊天模型在原有同一次回答中判断是否语音并选择语气，本机检查文字要求、群聊打扰和频率。独立语音进程共享一份模型，避免多号各自载入；闲置释放，失败回退文字，回执不确定不重复发送。

每个 QQ 分别导入参考音频及对应文字，可设置自然、开心、温柔、害羞、难过和认真参考。缺少对应语气就使用自然参考；默认参考来自设备系统 TTS，没有捆绑肥鱼人物录音或模型。支持 4/8 步生成；音高调整不作用于此引擎。预训练权重适用上游 CC-BY-NC 非商业条款，源码与其他依赖各自许可保留。详细边界见[语音说明](LIGHTWEIGHT-VOICE.md)。

修复 QQ 进程完全退出时接入无法自行恢复：按实例独立 HOME、缓存、运行目录和端口恢复 QQ；接入组件退出也限频恢复。保留本实例最近账号身份，主号暂时离线时仍阻止把同一 QQ 再启动到额外实例。手动停止不会被自动恢复逻辑重新拉起。

同时包含尚未单独发布的 [0.1.40 功能](RELEASE-0.1.40.md)：最多三个额外独立 QQ 账号、每号单独 API 和语音配置、模型输入查看、`＃量前5` 逐次用量、会话级发送保护和同轮智能语音决策。

## 验证

194 项 Node 回归、4 项电脑执行端隔离检查和 8 项 Android 框架检查通过；APK 签名、压缩对齐及内置资产逐项校验通过。

小米 2410CRP4CC / Android 15 已覆盖更新，保留账号和配置。本机中文短句约 4.7 秒、中英混读约 3.2 秒，含推理和 MP3 转码；仅为这台平板两次样本测量，不保证通用速度或听感。测试不调用付费模型。

已在设备同时运行主号及两个测试 QQ 实例，验证独立登录窗口与进程；定向结束一个测试实例的 QQ 后，仅该实例恢复，其他实例 PID 和主号连接保留；停止一个实例不影响另两个，测试配置已撤销。没有登录第二个真实 QQ，因此尚未验收多真实账号同时收发。长时间后台、其他手机、特定人物音色相似度及专门情绪表达仍待后续实测。

最终包再次完成中文与中英混读（约 4.2 秒 / 2.9 秒），前后主号在线。两个额外测试账号并发合成时共用一个语音进程、参考记录分离，加载后单次 PSS 约 434MiB；这不包含 QQ 与容器，也不是峰值上限。

另做了语音进程故障注入：合成途中只结束独立语音进程，本条试听失败、系统重新绑定后不重复提交，主进程 PID 与 QQ 在线状态保留；下一次显式试听成功。模型闲置释放检查通过。

## 更新

已有版本覆盖安装，不卸载、不清空数据。在“能力 → 语音”选择“轻量本机语音 · ZipVoice”后保存。额外账号在“QQ 多账号”中独立设置与登录；同一 QQ 不要登录两个实例。

离线语音让安装包增至约 730MB，旧版更新器的 600MiB 限制无法下载本包，因此 0.1.40 及以前首次升级需要从本 Release 下载 APK 覆盖安装。0.1.41 已将检查与流式下载统一限为 1GiB，保留 GitHub 来源、文件大小、SHA-256、包名、版本和签名核验；后续符合这些条件的版本可继续应用内更新。
