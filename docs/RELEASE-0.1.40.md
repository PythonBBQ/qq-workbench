# 七丘 QQ 工作台 0.1.40：独立多号、智能语音与模型输入查看

## 多号多开

设置→QQ多账号保留原账号，并最多新增3个独立实例。每个实例填写机器人QQ、大号、模型地址、模型、协议和自己的API Key，也可以复制一张卡片为独立快照。模型卡片后续切换不会改变其他账号的快照。语音、视觉Key同样独立加密保存。

额外实例分开HOME、QQ登录、SnowLuma端口与运行目录、图形窗口、助手进程、聊天记忆、发送账本和用量。号码与配置不符时不接入自动回复；原账号号码不能重复启动。启动、停止、登录窗口和随软件启动开关都在账号页；修改运行中账号须先停止，原登录与记忆保留。最多4号是配置上限，不代表每台手机有足够内存同时稳定运行4份Linux QQ。电脑Codex执行端目前由原账号接入。

## 智能语音和语气

能力→语音可选择智能、明确要求才发或优先语音。智能模式由聊天模型在原来这次回答里结合上下文选择语音/文字与语气，不额外请求一次判断；增加少量提示和标记Token。本机遵守明确文字要求，限制自动语音频率，代码、链接和长内容保留文字，群聊主动接话克制。语音倾向和20–180秒间隔可调。“语音说说”“发条语音”“来段语音”“说句话听听”等可直接触发尝试，不再在未尝试前让模型声称发不出去。

新增安卓系统TTS，使用已安装引擎，合成后在本机转成QQ语音。可选择可用音色、试听和向大号发送测试。系统音高/语速仅作轻微情境调整，不能冒充完整情绪模型。Azure晓晓按支持的情绪样式表达，其他音色保留基础合成。肥鱼声音服务可配置独立地址/Key与可爱/温柔声线；模型和GPU服务没有捆入APK，未部署前不启用该选项。研究、限制和候选项目见[语音引擎说明](VOICE-ENGINES.md)。

关闭语音时AI不能自行打开开关。生成失败本次使用文字；QQ发送超时或回执缺失不重发、不再补一份可能重复的文字。发送成功只表示QQ接口接受，实际收到另行核对。

## 自动暂停修复

旧逻辑遇到一次不完整发送回执会关闭整个账号的自动回复。本版保留该条“不确定”账本，且不自动重发，只对对应私聊/群聊短暂保护。连接核验通过且等待期结束后只处理新消息，其他会话继续。连续失败按30/60/120秒等退避，最长5分钟。用户手动暂停不被自动恢复覆盖；QQ掉线、系统冻结与发送未知不再混称同一种全局暂停。

## 实际模型输入与最近用量

设置→模型输入，按账号查看本次运行最近20个实际发出的聊天/辅助请求：角色、系统提示、筛选后记忆、历史和当前消息。记录实际Chat或Responses请求格式；文字每次最多64000字符并标明截断，隐藏密钥与图片数据/签名链接，不保存请求头。仅在进程内存保留，重启消失，可手动清除预览而不清聊天记忆。查看不调用模型。

大号可发`#量前5`查看最近5次模型调用逐次输入、输出、缓存及合计，支持全角数字、空格与括号。次数1–20，最新在前，各账号分开。缓存已包含输入，不重复相加；未报告用量显示未知，不当作零。一次聊天可能包括看图、搜索等多次模型调用，按实际调用列出。`#指令`已更新。

## 验证范围

190项Node模拟回归、4项电脑执行端隔离测试及7项Android框架检查通过，覆盖多号独立配置/鉴权/停止、号码校验、语音选择与情绪控制标记剥离、Feiyu一次提交与失败/超时、发送保护与手动暂停保留、输入脱敏和查询鉴权、最近用量及非大号拒绝。APK沿用原签名覆盖更新。

平板已验证系统TTS真实合成、QQ语音发送回执；用户确认收到测试语音及自然语言触发的普通聊天语音。额外实例验证了独立助手、VNC登录页和第二个Linux QQ进程，原QQ保持在线；测试实例未登录第二个真实账号，因此不宣称真实多账号收发验收。智能模型同轮选择和情绪样式经过模拟流程测试，长期听感和后台稳定性仍需在日常使用中观察。肥鱼GPU服务未在本机部署，接口测试不冒充真实肥鱼音频。
