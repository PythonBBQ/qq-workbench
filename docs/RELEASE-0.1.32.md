# 七丘 QQ 工作台 0.1.32：B站登录与实际视频画面

修复“让AI看B站视频，实际只查标题/简介”的缺口。直接发BV号、B站视频链接或分享卡片并要求看视频，会读取对应分P的完整最低码率视频画面；同一会话说“看完视频”可引用最近六条用户发言中的B站视频，不能从其他会话或AI自己编造的链接取目标。仅查标题/简介、关闭联网/视频或没有视觉模型时不下载。通用分享解析仍保留。

视频沿用0.1.31的每秒1帧、256×144画面、8帧低清拼图、每两分钟分段预算。10分钟以内完整分析；有多个分P时按链接的p参数选择对应一P，默认第1P，不会声称读取了其他分P。优先取DASH最低码率的独立视频轨，无需下载音轨；单文件仍限32MB。只接入可正常访问的普通视频，不绕过付费、会员、风控或登录验证；预览/试看、分段流、超过10分钟、时长不一致等不当作完整读取。暂不转录音轨和完整字幕。

在“能力→联网”及“能力→图片·视频”加入“登录B站”入口。工作台内打开B站官方HTTPS网页，用户自行完成密码、短信或扫码验证。检测到登录Cookie后向B站官方nav接口确认isLogin，成功才加密保存并热应用，无需手抄Cookie或重启QQ。敏感登录值不回传Activity结果、不写日志、不发模型，不获取其他应用的私有数据。高级手动Cookie入口保留，清除时同时清理本工作台浏览器的B站会话Cookie。网页登录页无原生JavaScript桥、不允许本地文件/明文混合内容、主页面仅允许官方B站HTTPS域名。

加入“打开哔哩哔哩App”按钮；它只负责跳转官方App，App内已有登录不会自动同步给工作台。扫码方式可用已登录的官方B站App扫描工作台显示的官方二维码，短信/密码也可在网页内切换。验证码、密码与最终登录确认需要用户本人完成。

“能力→图片·视频”新增B站链接/BV号分析入口。成功结果包含实际画面采样范围及模型返回的Token用量；错误携带本次失败原因和登录入口，不再将一次读取失败概括为软件永远不能看视频。B站Cookie仅发B站固定API，媒体请求仅允许B站CDN公开HTTPS域名、固定Referer、无Cookie/模型Key。签名媒体URL不注入模型、历史或笔记。安卓网络层流式下载到受限私有暂存文件，再使用已验证的FFmpeg顺序解码；成功或失败均清理文件，避免将完整视频经Base64传回网络桥。

验证：139项Node回归及7项安卓框架检查通过，覆盖真实QQ模拟路由的BV视频、续看、来源范围、画面数量、Cookie/签名地址隔离、短链分P、低码率选择、预览/超时长/私网/失败拒绝等。平板覆盖安装后，在正式应用内打开B站官方登录页面，显示官方二维码、密码和短信登录入口，未代用户填写凭据或确认登录。你截图里的公开视频BV1Umxc6JEdD已通过正式安卓网络桥实测：匿名访问取得约82秒视频，完整抽取82帧、11张压缩拼图，约5.29秒完成；测试不发送QQ消息、不调用付费模型。自动保存真实B站登录仍需用户完成一次官方验证后验收。本次APK保持原签名、校验资产一致，原QQ账号、API卡片与聊天记录保留。
