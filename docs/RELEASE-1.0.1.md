# 1.0.1 · 六种本机语气参考与电脑增强声音

个人测试构建，内部版本号 10001，沿用原签名。已在小米 2410CRP4CC 平板保留数据覆盖安装；本页不表示 GitHub 已发布此版本。

语音页新增“一键使用肥鱼六种语气”。自然、开心、温柔、害羞、难过、认真分别保存一段参考声音与对应文本，平板内置 ZipVoice-Distill INT8 根据本轮情绪选择参考，在 CPU 上现场合成新句子。导入后不需要电脑声音服务或语音 Key，也没有额外的情绪判断模型调用。原聊天模型的正常 Token 用量照常计算。害羞是参考表达的近似，不是新训练的专属权重；参考克隆的还原程度需实际试听。

六种个人参考由本机 IndexTTS2 与肥鱼完整 RVC 串行生成，共 832,952 字节，每段 3.10–4.04 秒。原始声源署名：星落落_oi / Esmerubphire；包内保留生成来源和说明。这是合成参考数据，不是训练录音、完整肥鱼权重或通用声纹 embedding。生成工具见 `tools/export-feiyu-reference-pack.py`，不会将私人生成数据自动提交到源码库。

可导入六种语气 ZIP 包。导入前核对清单、文件数量、文件名、大小、SHA256、PCM 时长及有效采样；所有音频通过后才整体替换所选账号的参考目录，原目录保留备份。各号共用一份推理模型，各自保存参考。手动单条参考导入仍可使用。

电脑端适配 IndexTTS2 Studio 与长篇语音工作台，提供肥鱼原始 CosyVoice3、IndexTTS 参考情绪合成、IndexTTS 后接肥鱼 RVC 三条路线。原始可爱、温柔配置已实际生成；IndexTTS 情绪合成及完整 RVC 均通过实际生成验证。修复原始肥鱼文本规范化组件每次启动下载其他语言资源的问题，使用带离线规则的 wetext 0.1.0。长篇台本及多轨编辑仍在电脑页面使用，详见 [声音工作台](VOICE-STUDIO.md)。

验证：27 项相关 Node 测试与 11 项安卓框架检查通过，其中覆盖六种参考暂存，以及哈希错误、缺文件、错误路径和空转写拒绝。六段生成参考经过独立离线转写核对；新增句子在真实平板分别使用六种实际参考合成成功，首次约 6.06 秒，后续约 2.81–3.91 秒，测试结束 QQ 仍在线。用户要求的六条试听已逐条提交给大号，接口均返回成功及消息 ID；实际听感以用户试听为准。
