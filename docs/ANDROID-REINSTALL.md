# 安装旧版时提示“已安装更高版本”

Android 根据包名和内部 versionCode 判断版本，桌面图标消失不代表所有安装记录都已移除。其他系统用户、应用分身、隐私空间仍安装同一包，或卸载时保留应用数据，都可能让旧版继续被拒绝。只有设备安装记录才能区分具体原因；不是缺少 Python 的证据。

正常升级直接覆盖安装，不先卸载。确需回退到 GitHub 已发布的旧版，可用桌面工具 `tools/android-reinstall.py`。它只处理 `cn.qqworkbench.assistant`，校验官方签名，打印各用户安装记录；使用 `adb install -r -d` 请求系统保留数据安装。不清除数据、不卸载应用、不删除系统用户、不修改系统安装策略。Android 多用户共享 APK 版本，回退会影响该包在其他用户中的代码版本。

2026-11-03 实机确认：OPPO PHU110 的机主空间 user 0 为 installed=false，但 system_clone（user 10）仍为 installed=true，全局版本是 1.0.8 / 10008。因此机主空间删除图标后安装 1.0.7 仍提示已有更高版本，原因是另一空间的安装记录，不是 Python 缺失或下载缓存。工具现已正确解析 Windows ADB 的重复回车、包记录及其后的同名 User 查询段，明确显示哪个空间仍安装，不能把解析失败当成卸载干净。

同签名官方 1.0.7 的 SHA-256 核对为 `de4df9417af9ba3113d30953299581d0446c366592938a0bbe3e3c444e80d147`。此机执行保留数据降级成功：全局版本变为 10007，user 0 恢复安装，user 10 仍保留安装，没有卸载其他空间或删除系统分身。

需要 Python 3.11+、官方 Android Platform Tools、Build Tools 35 和 Java。仓库工作站已配置工具路径；其他电脑可以用 `--adb`、`--build-tools`、`--java-bin` 指定。

只检查，不改变手机：

```powershell
python tools/android-reinstall.py
```

明确选择已下载的官方旧版 APK，保留数据安装：

```powershell
python tools/android-reinstall.py --apk "D:/Downloads/QQWorkbench-Android.apk" --java-bin "D:/Java/bin"
```

多设备时增加 `--serial 设备序列号`。当前用户仍安装工作台时，工具先停止该用户的工作台，并将设置、全部账号已保存的记忆、学习笔记、拉黑、用量、收藏音色和活动语音参考快照保存到 `build/private-reinstall-backups/时间/portable-data.private.tar`；无法备份或快照含不规范路径/链接就停止。安装后逐文件核对，并核对原来已安装的其他用户仍保留安装。它不是完整 Linux 容器/QQ 登录会话备份，也不是跨设备密钥迁移；跨设备仍应在应用内导出密码加密备份。私有快照可能含密钥，不要上传。

当前空间已经卸载时，工具不会凭空声称已备份或恢复被删除的数据。它记录所有空间的安装状态，保留其他空间数据，再为当前空间安装所选版本。此前通过系统卸载删除的账号、密钥和记忆，需要从可用的加密备份导入；不要直接把另一设备的 vault.xml 复制过来。

本项目预览包启用了 debuggable，允许 ADB 请求降级。部分厂商仍可能拒绝，工具会保留错误并停止，不自动转成卸载。拒绝时改用内部版本号更高的修复包；签名不符也不能靠降级参数解决。已卸载并删除的数据无法通过重新安装恢复。

如果确实要完全移除应用：先在各个有数据的空间导出备份，再在系统应用管理中移除该应用的所有用户安装，卸载时不勾选保留数据。只清理工作台本身，不需要删除整个系统分身或系统用户。普通应用无法自行替用户清除其他空间的安装记录，本工具优先走可保留数据的降级，不自动改成破坏性卸载。

ADB 无设备或无调试授权时不会尝试清理或安装。工具只负责安装回退；旧版数据兼容和实际 QQ 收发仍需另行验证，版本号核对不能替代聊天验收。


## 完整卸载计划

默认只读列出所有安装空间，不删除数据：

```powershell
python tools/android-reinstall.py --uninstall-all-users
```

确需删除本应用的所有空间安装时，可显式执行：

```powershell
python tools/android-reinstall.py --uninstall-all-users --apply-uninstall
```

执行前对每个已使用空间分别留存私有数据快照；空间不可读或安装状态不明则停止。仅系统明确记录 never-launched 且数据 inode 为 0 的空间可跳过空备份。卸载不使用 `-k`，完成后再核对全局包和各用户记录。此动作会删除本应用各空间的数据，私有快照不是跨设备 Keystore 迁移文件；保留数据回退优先使用 `--apk`，不要为回退先卸载。软件内的加密备份才用于换设备恢复。
