# 七丘 QQ 工作台 0.1.34：作者检索与上下文追问

修复“是找的作者吗？”被当成新搜索关键词的问题。工作台为每个账号、发言者和会话保留最近一次视频操作状态，区分按主题搜索、按UP主搜索、选中作品、分析完成与失败。追问只带入本轮真实记录，不重新搜索整句，也不把旧视频画面当成新观察。说“我是说UP主”“按主题搜”“再试试”可以承接刚才的关键词；作者重名时可用准确昵称、“第二个”或UID选择。状态在结束对话、清空上下文、切换身份/角色或过期后清除。

默认只按视频内容/主题搜索，不会因关键词恰好同名UP主而改找作者。只有“搜up xxx”“找UP主 xxx”等明确要求或后续纠正为作者时才启用UP主检索，支持“逼站”等平台别称。公共接口优先；公开请求失败且已配置有效B站登录时，最多尝试一次同一官方接口的登录请求，随后才使用公开网页检索，登录资料不发送到搜索引擎。按作者选片以UID核对，不能误选带前后缀的相似昵称。搜索结果中的高亮标签、空格和标点不再误伤标题匹配；官方结果被筛掉后也可尝试公开网页检索。作者已找到但没有可读作品、存在重名、接口受限和无匹配分别给出简短说明，不再连续重复一整段报错。成功回复附UP主、标题、BV与实际抽帧范围。

聊天会先理解用户是在纠正、追问还是要求执行，减少重复介绍能力和失败套话。最近一轮回答超过上下文预算时，保留原问题、回答开头与结尾，避免一次长回复让下一句失去上下文；不增加默认Token预算，也不声称改变模型权重。新视频分析仍隔离以前的视频证据。

验证：154项Node自动测试、7项Android框架检查通过，覆盖搜索→视频→模型→QQ的隔离模拟流程、作者身份、重名选择、失败后追问不再搜索、跨会话隔离和长回复预算。平板真实默认主题搜索“愚鸟渡渡”选择蛋挞兰花的二创视频BV1ycx76dEjW，完整读取79帧、10张拼图，约5.88秒；明确按UP主检索时选择同名UP主作品BV116pQ6jEtH，完整读取43帧、6张低清拼图，约4.87秒。明确查作者“妹存在感”时真实找到同名账号，但接口没有返回可读作品，未选相近账号代替。以上设备诊断未调用付费模型或发送QQ测试消息，不能代替真实模型回复质量评价。

新增本机离线中文语音识别：内置Sherpa-ONNX 2.0.1与发布者的int8中文Zipformer-CTC模型，包内携带锁定SHA256、来源及许可。B站DASH音轨单独下载，本机/QQ附件也走同一抽帧与声音处理流程；音频不上传识别服务。16kHz单声道、每30秒分段、2线程转写；只向模型提供当前两分钟对应的最多1200字，完整10分钟最多6000字，不另加文字模型压缩调用。自动转写不是可靠逐字字幕，外语、歌声、背景音乐和专有名词可能错误；失败时继续按画面回答，不编造对白。平板真实B站视频BV1Umxc6JEdD读取82帧与音轨，约16秒完成，转写338字、3段；未调用付费模型或发送QQ。离线识别测试音频5.61秒，识别计算约0.125秒、模型加载约2.432秒，速度随设备和时长变化。

普通QQ回复不再附搜索词、作品/BV、链接、帧数和采样收据。当前大号发＃来源时，才从当前私聊或群聊的真实记录中返回最近一次来源；指令不调用模型，其他会话与发言者不能读取该记录。普通联网回复也收起来源链接与引用编号。模型统一用“视频里”描述内容，不称“拼图里”；有真实转写才描述对白。工作台诊断与本机分析页仍保留范围/用量，便于核对。

沿用原签名，覆盖更新保留原账号、API、聊天和B站登录；10分钟、32MB、每秒1帧的画面预算不变。SnowLuma接入不变。
