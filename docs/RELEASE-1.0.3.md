# 七丘 QQ 工作台 1.0.3

本次整理语音页，并把长回复改为按句意连续发送多条语音。下载、资源重建和安装衔接集中在应用内，覆盖安装保留账号、密钥、记忆与参考音色。

## 语音

- 内置选择只保留三个音色卡片：系统自带、第一版肥鱼、新原声多情态。去掉Azure、QQ音色和电脑服务等重复入口；兼容读取旧配置，未删除第三方后端源码。
- 选择成功后在本机合成并播放“准备好了”。使用当前账号和新参考，不发送QQ、不调用聊天模型；旧试听结果不会抢占新音色。
- 第一版肥鱼保持原六语气参考，4步、语速-30%、音调0。新原声使用40段参考与9段原声短回应，4步、语速-15%、音调0。切换预设会恢复对应默认参数，之后可自行调整。
- 语速、音调、语气预设集中为卡片；记忆和高级参数折叠。参考音色的音调调整会实际用于输出，而非只改变界面数值。
- 支持单段参考音频和完整预设包。单段需1–10秒清晰人声及准确文字，可自定义名称；完整包校验六种语气、文件、哈希与格式。
- 导入声音保存在当前账号的本地预设库，可再次选择，长按移除列表副本。切换前备份旧参考。单段建立独立参考库，不混用旧人物语气或原声短回应；不会训练新权重。
- 长回复在合成前按标点、语意和长度拆分，每段合成后单独发送，收到上段回执才继续。短句保持一条。某段合成失败，仅把尚未朗读的内容转为文字；发送超时或回执不完整即停止后续发送，不自动重发。
- 保留完整尾音与每条音频末尾1.5秒空白。智能语音判断仍使用原聊天调用，不增加一次判断或改写调用。

## 更新

- 下载留在软件内，显示实际下载百分比；补丁与内置资源重建也显示实际字节进度，校验和签名检查显示阶段状态。支持后台下载、暂停与续传。
- 下载完成后在前台自动衔接系统安装确认，授权安装权限返回后继续。取消安装不会循环弹出，可手动继续。
- 系统完成覆盖安装后，恢复本地服务、同步新资源；旧会话先退出并释放运行锁，再更新脚本，避免继续使用旧代码或覆盖仍运行的资源。
- 自动尝试返回软件。安卓/厂商若阻止后台打开，使用更新通知返回；系统安装确认仍需用户操作，不能静默替换APK。
- 从1.0.0/1.0.1首次升到此版，仍需通过旧版已有方式确认安装；新衔接流程在本版安装后用于后续更新。
