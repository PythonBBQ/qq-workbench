# 两台设备切换

1. 旧设备打开“设置 → 备份与迁移 → 导出加密备份”，设置至少八位的密码，选择保存位置。
2. 将 `.qqwb` 文件通过系统文件分享、USB 或自己的存储方式传到新设备。文件含聊天和 API 密钥，请妥善保存，勿放进公开仓库。
3. 新设备安装工作台，完成首次使用协议后进入相同页面，点“导入备份并切换”，选择文件并输入密码。
4. 停止旧设备的本地服务，再在新设备连接 QQ；如果 QQ 要求验证，按官方提示完成。本机后台、省电与 Shizuku 权限需分别授予。

导入替换目标工作台的数据，不做两边聊天的自动合并。目标原数据自动保存在加密的“导入前备份”中，可在本页导出；使用本次导入所用密码解密。不会移动待执行任务、发送队列或复制 QQ 设备登录凭据。以后切回时，从最近使用的设备再导出一份最新备份。

应用不会保存你输入的备份密码。密码遗忘或备份损坏时，不能绕过加密恢复。
