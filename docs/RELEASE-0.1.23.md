# 七丘 QQ 工作台 0.1.23：表情发送与AI自动备注

修复收藏表情没有备注时全部被排除的问题。未备注表情仍可发送；明确说“发个表情”“来个表情包”时，工作台直接使用SnowLuma收藏表情发送接口，无需模型先生成回答。平时聊天仍可由模型根据简短含义选用收藏表情。收藏操作仍只允许当前设置的真实主人。

增加“AI自动备注新表情”。启用表情后，后台使用当前视觉模型读取未备注的收藏表情，为其生成简短中文含义并写入QQ备注。已有备注保留，写入前再次核对，尽量避免覆盖期间手动填写的内容。每批最多6张，逐张处理，不把聊天记录交给备注模型。支持关闭自动备注及手动启动一批。

模型看不清或接口失败时不编造标签；失败有冷却，重启后不会重复尝试未确认的QQ写入。账号、主人、配置切换会取消旧任务。没有视觉模型时显示原因，表情发送依然可用。图片数据只交给用户配置的视觉模型，模型密钥不发送给图片服务器。

验证：100项Node测试通过，覆盖未备注表情发送、自然请求、群聊/私聊、语境选图、视觉备注、保留手工备注、账号切换取消、失败冷却及未确认写入跨重启去重。模拟发送测试未向真实QQ聊天发消息。6项Android框架检查通过。已在原小米平板覆盖安装0.1.23 / versionCode 24，正式QQ已连接，自动回复开启。平板原有6张空备注表情已由当前视觉模型生成备注，QQ全部返回成功；重新读取确认6张均有备注。未向真实QQ聊天发送测试消息。

可直接覆盖安装，保留QQ登录、API密钥及原配置。
