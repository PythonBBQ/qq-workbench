# 七丘 QQ 工作台 0.1.38：常提词辅助记忆

加入可关闭的本机词频加权，在酒馆→记忆查看。用户自己的直接聊天文字中，同一个词在不同轮次间隔至少2分钟再次出现，会提高相关记忆的检索优先级；间隔超过30分钟、跨天有额外加分，长期不提逐渐衰减，强度有上限。每条消息一个词只计一次，短时刷词不累加；每会话最多128个词，账号、角色、群聊和发言人原有隔离规则保持。旧记忆文件兼容，词频从更新后的新聊天开始积累。

权重只用于挑选已有明确偏好和相关旧摘录，不把常提直接解释成喜欢，不根据助手回答、视频转写或网页资料增加用户词频；明显引用、链接、指令及密钥类文字不计入词频。明确表达的同一对象喜好纠正替换旧偏好，当前消息始终优先。普通提及不会自动生成一条喜好记忆。

相关旧摘录去重，具体问题不再用无关摘录填满预算。偏好仍最多6条、1600字符，旧摘录保持原预算；不把全部词频表或数值发给模型，不增加抽取/嵌入API调用。计数本身不消耗模型Token，实际输入量会随选中记忆改变，不承诺固定降幅。计数与记忆同样本机加密保存；结束当前对话或清空上下文会清掉其词频，明确偏好按原规则保留，删除整个会话会删除该会话全部记忆。

调研MemOS、Letta/MemGPT、Mem0、Memobase、memU，参考相关性优先、重要性辅助和时间衰减的设计。没有整套引入服务、向量库或云端记忆；项目取舍与源码链接见[调研记录](MEMORY-PROJECTS.md)。尚未实现向量语义召回，不应将本版称为完整语义分层记忆。

验证：165项Node回归与7项Android框架检查通过，覆盖限频、跨日增强、衰减、上限、负面偏好纠正、相关摘录排序和去重、无关内容剔除、加密重载、角色/用户隔离、关闭与删除。测试不调用付费模型或发送QQ消息。沿用原签名，覆盖更新保留账号、API、B站登录、人设和现有记忆。
