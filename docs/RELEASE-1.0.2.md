# 1.0.2 · 多情态本机语音与完整收尾

本机参考语音新增“一键使用新角色 · 原声多情态”：40段中文参考、9段原声短回应，包含自然、开心、温柔、害羞、失落、认真六种表达。问句、安慰与睡前轻声分别选择参考；普通聊天不会随机混入轻声。正文已有“嗯、啊、诶”等明确开头或独立短回应时，可使用对应原声，不随机插入声音或改写回答。

修复轻声尾音被裁去、收尾过早的问题。保留原波形全部尾部，只在原波形之后平滑释放；本机参考音色、Kokoro、系统TTS和肥鱼服务的WAV转换路径校正音量，并在整条语音结束后追加1.5秒空白。轻声使用较低响度目标。分句之间计算已有停顿，不重复叠加整条收尾空白；合成片段必须全部完成后才交付，失败回退文字。

包含此前1.0.1个人测试版的六种肥鱼参考、一键导入和整目录备份；旧声音不会被更新自动覆盖，可在语音页切换。四个账号共享推理模型，各自保存参考和选择状态。参考包检查文件名、大小、哈希、音频格式与清单，拒绝路径穿越和未登记文件。

语音采用现有ZipVoice本机参考条件合成，中文参考由本机IndexTTS2制作，没有训练新权重。情态选择及本机合成不额外调用聊天模型，原聊天模型正常用量照常计算。害羞与ASMR轻声属于参考表达近似，非专用耳语或双耳模型；偶发错读仍可能发生，收尾空白无法补回模型未生成的字。
