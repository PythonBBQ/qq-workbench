# 本地角色原声预设

本功能把用户录音整理为数据格式的语音参考库。电脑使用现有 IndexTTS2 生成中文参考，安卓使用现有 ZipVoice 离线合成新句子。没有进行模型微调、蒸馏或新权重训练，不把参考克隆称作训练成果。

## 使用与回退

支持本功能的本地安装包中，进入“能力 → 语音”，点击“新原声 · 多情态”卡片，即可导入参考并启用本机语音。主账号同时保存设置；其他账号导入后需保存该账号配置。原参考整个目录保留备份，“第一版肥鱼”卡片可重新启用原预设。

六个基础情态沿用 neutral、happy、gentle、shy、sad、serious，不增加模型的输出标记种类。丰富预设可在每种情态下存放最多八个参考，按问句、安慰和本机计数选择。轻声参考有独立 soft 标签，普通聊天不随机选入；睡前放松正文或用户明确要求轻声时优先选择。

本次个人包共40段中文参考、9段原声短回应，来自39段不同原录音。六种情态的参考数依次为6、6、8、8、6、6。小模型的参考引导强度经过两组新句比较：自然、开心、温柔和害羞通常采用2，失落和认真保持1；再经24条易错参考复测，gentle-6单独采用1、shy-2单独采用3。参数属于参考元数据，旧预设未填写时仍保持原来的1，不修改旧音色的全局参数。声纹诊断只用于同条件比较，不能换算成还原百分比。

“ASMR”表示轻声参考的表达近似，现有引擎并非专用耳语、双耳空间音频或 ASMR 模型。不要在界面中承诺这些未实现的能力。

## 原声语气词

录音中的独立语气词可作为原声短回应使用，并仅用于以下两种情况：

1. 回复正文完整匹配某个语气词别名与标点。
2. 回复正文以明确写出的语气词及标点开头，后文不少于四个字符。只把这个已有开头替换成相应原录音，后文仍按原文合成。

不额外随机插入笑声或呼吸；不将问句与陈述句的别名混用；不从身体接触或性化场景提取喘息。短回应也绑定当前情态的预设来源，手动更换该情态参考后不能继续引用旧角色录音。

整个音频完成后才交付；任意后续片段失败时，不单独发前面的原声语气词。所有账号共享模型但分开保存声音与选择计数。

## 尾音与收尾空白

原生合成后不再裁去句末低音量采样，也不在最后一个音节上淡出；只在原波形之后加12毫秒平滑释放。分句连接保留所有原采样，已有的静音计入停顿，避免叠加多余空挡。

本机参考音色、Kokoro、系统TTS和肥鱼服务的WAV交付路径，在整条合成完成后统一经过有限动态音量校正、响度处理，最后追加1.5秒空白。普通说话目标约-19 LUFS，轻声约-23 LUFS；轻声保持相对较低音量。没有使用静音门、尾部裁剪或整条150秒硬截断。仅在整条末尾追加这段空白，各分句末尾不会重复追加。

1.5秒空白是播放器收尾余量，不能补回模型从未生成的字。仍用预先断句、分段完成数和异常短片段检查降低截断风险；转写也不能保证每个语气词准确。Azure直出MP3和QQ远端音色URL不经过上述本机WAV转换。

## 数据格式与安全

schema 1 保持原六参考格式兼容；schema 2 增加 variants 与 acknowledgments。导入以文件大小、SHA-256、明确文件名、参考文字、别名和情态白名单校验，只接受数据。整目录暂存后替换并保留旧目录，拒绝路径穿越、重复条目与未登记 WAV。外部预设不会加载可执行文件。

个人素材默认仅保留本地，不随处理工具自动发布。2026-11-01用户在本地试听包交付后明确要求“github发布”，本次据此将选定参考与原声短回应随1.0.2签名发行补丁发布；原始素材压缩包、完整源录音和私人配置不提交源码仓库。源码只提供处理工具，不包含录音二进制或密钥。素材与第三方模型保留各自权利，源码许可不授予其额外权利。

## 验证方式

`prepare-character-preset.py` 保存原素材选择和渲染签名；`review-character-preset.py` 与 SenseVoice 进行两路文字校验；`probe-character-preset.py` 在应用 UID 下的独立测试目录执行真实 ARM64 原生合成，不覆盖实时配置，不发送 QQ 消息。

`build-character-listening.py` 生成原声、电脑中文参考、平板新句及 4/8 步试听对比。`review-character-identity.py` 使用已有 CAMPPlus 模型做声纹向量诊断，其余弦值受语言、情态和时长影响，不能当作还原百分比或自然度分数。

`verify-character-delivery.mjs` 用真实平板合成文件执行生产`synthesize`转换路径；`review-character-delivery.py`测量完整时长、最后1.4秒静音和采样峰值。`verify-tablet-delivery.py`另在平板自带FFmpeg上验证普通与轻声编码。所有验证使用隔离测试数据，不发送QQ消息。

转写校验会混淆语气词、同音字和儿化音；时长检查只能发现明显截断，不能保证每个字准确。自由合成仍可能偶发错读，最终声音还原程度需要实际试听判断。

1.0.3：三个内置卡片切换后本机试听“准备好了”。自导入完整包或单段音频会存入各账号独立的本地预设库；单段录音的所有语气共用该段参考，不继承之前人物的变体和短回应。长文本在合成前分成多条语音，逐条发送；每条仍可在引擎内部按短句生成，但不会再将整篇长文本拼成一条QQ语音。
