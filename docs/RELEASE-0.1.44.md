# 0.1.44 · 修复加密配置导致的启动中断

修复登录页出现 `AEADBadTagException` 后服务直接退出、环境补齐无法继续的问题。它表示旧加密记录校验失败，与缺少Python不是同一故障。

- 加密仓库使用共享锁，避免界面和后台同时创建同一系统密钥或本机凭据。读取旧记录不再自动创建替代密钥。
- 失效项单独隔离。本机接口、QQ窗口和记忆密钥可重新生成；替换前保留原密文。模型Key、卡片和网站登录需要重新填写或登录时会提示，不自动编造、不静默切换到旧模型。
- 开始使用、模型和诊断页增加恢复说明；新填写的模型配置会明确保存并启用。保留QQ容器、账号、聊天和设置。
- 沿用0.1.43的窗口就绪检测及组件补齐。电脑维护工具支持检查多用户安装记录、请求保留数据安装旧版；发布工具支持失败补传、远端哈希核验后再公开。

安装：直接覆盖更新，内部版本号45、原签名；无需卸载或清空数据。首次恢复组件时保持联网并等待准备完成。旧密钥确实丢失的记忆无法凭空恢复，原记忆文件会保留并暂停持久化。

本次验证：已在OPPO PHU110 / Android15通过USB覆盖安装，手机安装包哈希与GitHub一致，已备份配置。启动已越过原加密错误，九项实际环境检查全部通过，QQ登录网页返回HTTP200。尚未在该机完成QQ登录与聊天收发验收。没有发送QQ消息或调用付费模型。

更新检查：手机内正式更新器已返回 `v0.1.44 / 当前已是最新版本`；公开版本页与APK下载返回HTTP200，远端大小和SHA256匹配。该检查记录对应0.1.44发布时的状态。当前请优先下载1.0.0；发行版保留1.0.0和本版，源码和标签历史保留。0.1.45开发草稿未公开，已合入1.0.0。

维护说明：本次电脑USB连接问题另行定位为WinUSB缺少ADB接口注册；经用户授权补齐后，有线ADB已识别OPPO。该电脑端维护不是APK自动安装驱动的功能。安卓安装确认与QQ官方身份验证仍由系统及用户完成。
