# 七丘 QQ 工作台 1.0.8

本版集中重构服务启停、备份导入和更新交接，音色与语音模型沿用 1.0.7。没有加入此前 MOSS 试听分支或替换参考音色。

## 备份、导入与运行锁

- 修复初始化进程仍运行、界面已显示停止而备份一直提示“运行锁未释放”的问题。等待启动线程、清理本应用的残留容器并实际核验 flock；不删除锁文件，也不停止外部 QQ。
- 备份、导入、环境重检、清理和安装交接使用同一维护流程。记录原运行意图，中断后先恢复事务再启动服务。
- 新增跨进程数据锁，防止独立语音进程与导入同时读写音色。维护具有独立前台通知，停止 QQ 后仍能完成加密操作。
- 导出先在私有目录生成完整加密文件；导入提前检查设置结构和配置格式。错误密码、损坏文件或无效设置拒绝提交，原目标仍有导入前加密备份，提交失败回滚。

## 补丁与安装

- 下载阶段留在应用显示进度，保留聊天；下载、补丁重建和签名核验完成后才停止会话并进入系统安装。取消安装保留包并恢复原运行意图。
- 根据真实 APK SHA-256 选补丁；本次同时提供完整 APK，找不到对应补丁时可选择整包。不是用补丁文件直接安装或热加载代码。
- 备用清单增加公开资源 API 地址，下载公开入口刷新缓存键，保留 GitHub API/网页通道切换、断点续传和校验。不会把全部通道失败说成“已是最新”。
- 显示版本 1.0.8，内部版本 10009，以便覆盖此前未发布的 10008 测试包。旧测试包若不提示同名新版，可直接下载本版完整 APK 覆盖安装，不先卸载。

## 卸载与回退

Android 的不同空间共享应用版本。电脑工具修复多用户安装记录解析，显示哪些空间仍安装；同签名回退先备份，再请求保留数据降级。本机曾确认主空间卸载、分身仍留新版，保留数据回退成功。

新增完整卸载的只读计划与显式执行选项，先备份所有已使用空间；安装记录不明或数据不可读时停止。不会悄悄卸载所有空间、删除整个系统分身或恢复已经删除的数据。具体步骤见 [安装与回退](ANDROID-REINSTALL.md)。
