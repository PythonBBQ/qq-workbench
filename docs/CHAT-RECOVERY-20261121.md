# 2026-11-21 本地维护：自动恢复、分条回复、场景与记忆

当前目标包：1.0.9 / 10027。按用户要求撤回 10022～10026 的语音实验，恢复原合成方式，同时保留本文件描述的聊天和发送可靠性修复。详见 [语音恢复记录](VOICE-RESTORE-20261121.md)。下文旧版本测速仅为历史记录，当前参数已不同，不代表恢复包速度。

同签名覆盖安装；沿用原 QQ 登录、API 卡片、加密记忆及 1.0.7 音色资源。本轮不发布 GitHub，不重启手机，也不读取手机密码。

## 行为

- 按用户最新要求，移除日常一到三个短句及“轻松话题简短”的默认提示，回复按话题自然展开，不新增字数限制。自然段分别发送；长段落在完整句子之间拆分，最多六个气泡，剩余内容合并保留。链接和代码块保持完整。管理指令、用量记录和 Codex 回执保持原交付方式。原有用户可调 Token 上限保持。
- 每段先核对权限，再等待 QQ 发送回执。首条立即发，后续文字气泡间隔 1.5 秒。已经开始发送的一轮，在普通暂停、同账号调整人设/模型或收到新消息后继续发完；暂停阻止后续新任务。换 QQ、换主人、拉黑或失去好友权限，以及真实发送回执不确定时停止，不向新账号漏发，不重发不确定消息。整段回答成功后按一轮逻辑对话存储。
- 文字回复只有部分段落获得完整回执时，将已确认部分连同“后续内容未确认”标记存为一轮记忆；未确认段落不进入回答历史，账号切换或记忆清理后的旧任务不能恢复记录。不完整轮次经加密保存后仍可回忆，但不进入训练样本导出。
- 新对话轮次在本机保存时间。间隔三十分钟或用户明确换话题时，不继续注入旧场景的实时聊天历史；持久偏好和过去事件仍按需检索。五分钟以上间隔也提示模型重新判断情境。没有时间的旧记录不伪造日期。
- 日常完成事项按用户原话进入有日期的事件记录；不以助手自称完成作为操作证据。旧摘要不再阻断对原始细节的检索。过滤“现在、已经、可以”等通用词造成的无关召回。既有加密格式和账号、联系人、群、角色隔离保持兼容。
- 固定聊天和基础语音规则放在可复用的系统前缀；本轮检索、时间、记忆和语音形式覆盖放在当前输入末尾，不反复存进聊天历史。分段、场景判断和事实检索均不增加模型调用。
- 缓存统计区分服务商没有报告缓存数据与明确零命中；新记录可在 `#量前数字` 查看未命中数量。服务商缓存命中仍由服务商决定，不能保证某个命中比例。
- 开机和更新后预先持久化恢复任务；一次启动未完成会有界重试，并保留系统后备检查。用户手动关闭、尚未同意协议或迁移维护中均不自动开启。首次开机需要正常解锁后才能访问账号密钥。
- 接管原有本机会话后继续监测存活。连续三次本机接口未响应且精确运行锁确认释放，才进入有界恢复；原会话持锁或锁状态无法核验时保留原进程继续检查，避免重复启动 QQ。
