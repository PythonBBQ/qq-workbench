# 主动聊天详细规则 · 10035

2026-11-22。本地规则与分词计算，不额外调用分类模型，不修改模型权重。到达设置间隔只代表可以重新评估，分数不是按检查次数累积。默认门槛60分，可调45～95分。

设置入口：回复与群聊 → 主动找主人聊天。这里可查看当前评分，进入候选话题、完整规则，以及七类话题偏好（各-15～+15分）。查看不会生成或发送消息，评分读取已保存的设置。

当前快照与上次实际尝试分开显示。当前分数达标且等待条件满足，只表示调度器可考虑生成；上次实际尝试显示当时的评分和结果：生成中、模型跳过、格式无效、内容重复、取消、失败、QQ发送未确认或QQ已接受。失败/跳过后的冷却会显示具体原因；不再把模型主动跳过误写成“只差间隔”。修改评分偏好或门槛会作废按旧规则生成、尚未投递的草稿。

## 如何选话题

只从当前主人对当前小号的真实发言提取候选，按词项重叠聚合具体话题；助手自己发过的话不能成为主人兴趣证据。同类可以有多个候选，例如做饭和游戏各自计分。优先最高分，同分取最近证据。完成、拒聊、代词续接采用本地启发式判断，不是模型语义理解，复杂省略仍可能识别不准；查看候选可核对实际判断。

“想你了”“喜欢游戏”等有意义短句不再因不足五字被过滤；你好、好的、收到等普通问候仍不构成话题。主人句子里的作品引号不再导致整句丢失，明确的引用、转述和指令仍不当作主人直接偏好。一个候选的标识由起始证据确定，追加描述不重新生成标识；安排保留该话题最近一次明确时间，不会因后续没提时间就遗忘它。

证据最多回看30天；生成时携带选中话题的证据、最近聊天及近期主动消息，并带记录时间。旧记忆检索也围绕选中的具体话题。生成提示明确要求不把旧场景当现在，不假定计划已发生，不反复问饭或要求解释为什么没回复；没有合适的新切入点可跳过。

各项相加，不将总分强行压成百分比。门槛之外，QQ在线、模型配置、自动回复、空闲期、最短间隔、开机缓冲、免打扰和用户设置的每日上限仍需满足。次数不限不会撤掉评分和免打扰。明确说不要主动找我仍暂缓24小时，明确允许可提前恢复。

例如周一下午15点，一次90分钟前的兴趣发言，没有近期联系和结束语时：时段6 + 兴趣24 + 续聊依据10 + 新鲜度14 + 自然间隔10 = 64分，默认门槛60，有机会生成；旧版同样情况只有54分。只有问候或没有话题时仍无候选，不会靠等待刷到门槛。

## 费用、状态和验证

低分不预占生成次数，也不调用模型；通过后最多生成一次，生成仍可能选择跳过。跳过或失败按已有间隔规则冷却。主人新消息优先，取消尚未投递的主动草稿。未确认发送不会自动重发，后续主动评估不能充当同一消息的重试。

饭点类别不再成为整天禁言条件：午饭和晚饭不因同属“吃饭”而全部拦截。相同正文和高度相似开场按真实联系时间过滤近24小时，过期后解除；旧版没有时间戳的永久正文哈希不再用于拦截。确定或不确定发送均记录近期正文哈希，不自动重发未确认消息。

普通调度状态只存联系时间、类别、话题哈希和反馈等元数据；原文证据沿用聊天记忆，设置里的评分展示可看到相关原话。交付核验记录剔除原话。此次测试使用假QQ和假模型，不以离线模拟声称真实主动消息已送达。
