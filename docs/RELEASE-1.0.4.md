# 七丘 QQ 工作台 1.0.4

修复能发现新版但下载一直超时的问题。平板此前可访问GitHub API，却无法连接github.com的下载入口；仅能读取版本信息不代表补丁可下载。

## 下载与安装

- 优先使用发行版元数据中的GitHub官方资源API，按二进制下载；失败时切换官方发行地址，随后可重试API。无需模型密钥或GitHub登录，也不使用第三方镜像。
- 两条通道共用同一摘要、文件大小与续传缓存；切换时从已有字节继续，保留SHA-256、范围、重建目标和安卓签名检查。范围错误或摘要错误不通过换源掩盖。
- 点击更新后留在软件内显示实际下载进度，不跳浏览器、不主动停止聊天。下载完成后显示补丁整合进度，校验成功才进入系统安装确认。安装后同步资源并恢复服务。
- 下载按钮只做地址格式检查，DNS与网络检查交给下载线程，避免点击时卡住。通道切换、下载完成、补丁整合和网络不可达分别显示状态。
- 保留1.0.3的三种内置音色、自定义预设库和长文字分段发送语音。

## 旧版首次修复

旧版已安装的下载代码不会随发行说明改变。如果旧版网络无法到达github.com，需先用本地同签名APK覆盖更新一次；不要卸载或清空数据。本版安装后，后续补丁使用新的应用内下载通道。

1.0.x继续发布按原始签名APK哈希匹配的差分补丁，保留1.0.0基础整包。系统安装确认仍需用户操作；应用不承诺静默安装或绕过系统限制。
