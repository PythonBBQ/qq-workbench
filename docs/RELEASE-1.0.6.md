# 七丘 QQ 工作台 1.0.6

平板新增原版 ZipVoice FP32 完整模型，可在本机使用参考音色合成中文。此前使用 ZipVoice-Distill INT8；本版实际增加了未蒸馏、未 INT8 量化的模型文件，同时保留轻量模型供切换。新原声卡片默认选择已选听感：日常和温柔32步，害羞16步，第一版肥鱼仍选择原轻量路径。

## 语音变化

- 语音设置增加模型与 4/8/16/32 步预算。完整模型使用 16 或 32 步，轻量模型使用 4 或 8 步；选择从设置、账号配置、预览一直传入实际原生推理，返回真实模型名称和步数。
- 完整模型较慢，聊天回复在合成前拆成更短的多条语音，按顺序发送；32 步的分段更短。任一段失败时，仅剩余未读内容转文字；发送结果不确定时不重发。
- “嗯、啊”与正文整句生成，不插接独立原录音。用户认可T02（16步害羞）、T06（32步日常）与T07（带“嗯”的新句），因此恢复此前已选短参考，撤下被评价为假的T04“啊”开头试验参考。
- 语气预设新增可手动选择的“软绵 · 暧昧”：在现有音色下使用害羞轻声参考、ZipVoice相对语速减5%，不额外变调、不插入喘息录音。聊天与本机试听使用相同映射；本条明确要求正常说话、关闭语气变化时不强制轻声。没有新训练的情绪模型，听感仍需试听。
- 普通害羞语气也相对设置语速减5%，软绵保持R04试听的语速，不重复叠加。
- 口语提示允许按情境自然用一处语气词，保留重点与正常停顿；不要求每条加语气词，不生成呼吸标签或动作旁白。情绪仍由聊天内容及参考录音影响，不能承诺仅靠情绪名称就实现害羞等听感。
- 保留完整句尾和 1.5 秒结束空白。完整模型恢复较自然的句间空白比例，语速和音调默认均为 0。

## 真机验证与限制

小米平板约 12GB 内存。隔离测试中，约 5 秒的中文音频，16 步生成需要约 30–37 秒，32 步约 64–77 秒；测试进程 PSS 约 0.94–1.00GiB，不代表应用及 QQ 所有进程的总内存。完整模型加载约 2.6–3 秒，连续测试期间 QQ 保持在线。

4 条同句模型对照、2 条语气词新句对照完成合成和本地转写检查，检查未见明显漏句。转写检查不能证明音色还原、自然度和情绪已改善，听感须以实际试听为准。没有训练、蒸馏或更改新权重；参考库里的电脑合成片段明确保留来源，不冒充原录音。

模型使用官方发行文件，下载分块校验范围、整包 SHA256，再按固定清单打包。模型文件内置 APK，首次使用自动校验准备，平板运行不需要电脑语音服务，也不消耗聊天模型 Token；相比旧版首次下载会增加约 459MB 模型资源。

第三方权重、代码和参考音频各自遵守原有许可；本项目源码许可不替代模型许可。ZipVoice Emilia 预训练权重为非商业许可，来源和声明保留于应用第三方说明。

230 项 Node 检查与 12 组安卓原生检查通过，包含模型预算传递、长语音提前拆分、失败后未读内容回退、预设隔离及本地预览。更新继续使用相同签名与 1.0.x 差分补丁。
