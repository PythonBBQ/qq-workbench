# 七丘 QQ 工作台 0.1.28：两字快捷指令

新增“＃指令”完整菜单。全部新指令均为“＃＋两个汉字”，同时兼容半角#、全角＃，参数前加空格或冒号；数字参数亦可紧跟，如“＃亮度50”。“＃帮助”是菜单别名，“＃联网”是搜索别名。仅最新设置的大号可用，群聊直接发指令即可，不必另加@deepseek；旧自然说法、@codex与#sl等用法保留。

常用：＃状态、＃用量、＃暂停、＃继续、＃结束。暂停只关闭自动聊天，主人菜单、状态及已有管理能力仍可使用；恢复需已启用模型卡片。“＃结束”结束当前会话并清除该段聊天上下文，保留已明确保存的偏好，之后群聊恢复原来的唤起及参与规则。命令识别、菜单、状态、用量和参数检查在本机完成，不调用模型。搜索、草稿及生成动态仍按原服务调用和用量统计。

聊天：＃搜索 关键词、＃浏览 HTTPS网址、＃收藏、＃表情、＃语音 文字、＃开音、＃静音、＃音色 晓晓、＃语速 -20、＃音高 10。“＃语音”朗读指定文字，仍需原语音服务配置，不是唱歌；唱歌功能未加入。

空间：＃动态 正文（不填则生成并发布）、＃草稿 主题、＃发布、＃空间、＃自发、＃停发、＃更新。“＃动态”会发布到小号空间，“＃草稿”只保存草稿，“＃发布”发布已有草稿；原每日上限、连接检查和不确定结果不重发策略继续生效。“＃更新”只检查更新，不代替系统安装确认。

设备：＃电量、＃存储、＃应用、＃屏幕、＃打开 B站、＃亮度 50、＃音量 3、＃点击 300 600、＃滑动 300 900 300 300 300、＃按键 返回。支持桌面、返回、最近、回车、亮屏、息屏；滑动毫秒可省略，默认300。设备开关和Shizuku授权仍需开启，参数在执行前校验，非法参数不交给模型猜测。

群管理：＃拉黑 @某人、＃解黑 @某人、＃名单，也支持指定QQ号。继续使用原群聊隔离和真实大号核验，不允许处理主人、机器人自己或多个模糊对象。全角与半角前缀不改变权限。

验证：123项Node模拟回归通过，含菜单零模型调用、暂停后查询/恢复、非大号拒绝、群聊无需额外@、设备范围检查、引用不执行和参数错误不执行。全部安卓源码、原签名、对齐和资产哈希通过。真实QQ指令收发不由模拟测试代替，本次不自动发送测试QQ消息。原账号、密钥、聊天及酒馆设置保留，可覆盖更新。
