# 七丘 QQ 工作台 0.1.24：修复续发表情变成文字

0.1.23 首次明确说“发个表情”时能够发送图片，但“还有其他表情吗”“没表情啊”“再试试”等续发请求未接入表情路径。旧内部记录“（发送了一张QQ收藏表情）”进入模型上下文后，被模型照抄成聊天文字。已通过真实QQ双向历史只读查询确认：此前首次回复是image，后续占位回复是text。

补齐询问其他表情、换表情和上下文续发的判断。短句“再试试”只在当前聊天近期确有表情请求时续发，不借用其他私聊或群聊的状态；中途转为搜索等其他话题后，重试不会再误发成表情。每个会话独立轮换表情。

旧占位和新内部回执记录不再交给模型作为聊天正文。若模型仍模仿旧占位，输出会被拦截并转成实际收藏表情；纯表情路径只构造图片，不夹带内部文字。QQ接口接受只表示提交成功，不会据此编造对方已收到或网络卡顿。原有收藏、AI备注及主人权限保留。

验证：103项Node测试通过，包括截图完整顺序、旧占位回显拦截、会话隔离、切换话题后的重试和轮换。发送使用隔离模拟；本次真实QQ仅只读核查已有历史，未主动发送测试消息。

可直接覆盖安装，保留原账号、密钥、收藏备注和聊天记忆。
