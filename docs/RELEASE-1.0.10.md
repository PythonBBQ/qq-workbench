# 1.0.10 · 登录输入、当前版本分享与主动聊天

2026-11-22，内部版本号 10035。本地完整 APK，沿用原签名，可覆盖 1.0.9 和此前 1.0.10；本次未发布 GitHub。

10035 修正评分与执行不一致的问题。移除饭点类别整天去重的残留限制，实际重复内容仍按24小时过滤；加入上次实际尝试记录，区分生成、模型跳过、格式无效、重复拦截、取消、失败、发送不确定和QQ已接受。当前评分与上次实际尝试的分数分别显示，达标不再被描述为已经发送。修复短句被忽略、话题补充后标识改变、计划时间随补充丢失及重叠扣分。为陪伴/兴趣/日常/安排增加可见的10分续聊依据，让普通白天的有效话题有机会达到默认门槛；没有话题、只有问候或一次性查询不会因此触发。配置门槛未改，模型仍可跳过。

10034 细化主动聊天评估：同类话题按具体内容区分，结束一件事不再给其他话题扣分；增加常聊时段、按原记录日期理解的计划时间、同话题重复和真实回应反馈。反馈只作最多±8分的轻微调整，不将未回复认定为不喜欢。新增「主动话题偏好」七类独立调分，以及评分中的候选话题、证据日期、开场方向、各项分数与评分规则。默认设置不变，沿用用户当前配置。详见 [主动聊天详细规则](OWNER-CHAT-SCORING.md)。

10033 将主动聊天改为本地评分评估。达到设置间隔只是检查机会；按设备当地时段、陪伴/兴趣/日常/安排/求助/查询等话题的使用程度、话题新鲜度、自然间隔计分。使用程度按真实主人发言所在的不同会话和天数计算，同一会话刷词不叠加。默认门槛60分，设置中可调45～95分；「查看当前评分」显示各项加减分和等待原因，查看不调用模型、不发送消息。低分不预占生成次数、不调用模型，分够只生成一次，模型仍可以跳过。

睡觉、忙碌、告别、已结束话题、刚联系过、近期同类话题及未回复都会扣分；结束语和未回复的扣分随时间减轻，返回聊天会解除对应结束状态。取消「已发一次必须收到回复」和「每餐只能一次」的硬限制：主人不回复时仍能在后来合适的评分机会主动开启其他话题，不催回、不追问上一条。未确认发送仍不自动重发；它计入本次联系，后续评估不能充当重试。明确的免打扰、关闭、不要主动找我的要求保留。

10032 的「每日次数不限」、2分钟最小联系间隔和空闲等待保留；有限每日上限也保留。无限表示没有每日次数上限，不表示每两分钟必发。主动评分不依赖额外分类模型，不每分钟累加等待积分；等待最多10分，没有有效话题或只有过期话题不会因等得够久就自动发消息。

QQ 登录窗口增加「输入账号」「输入密码」「打开键盘」。先点中官方 QQ 窗口里的目标输入框，再使用对应按钮。原生编辑框提供安卓键盘，通过本机 noVNC 键盘通道填入选中的字段，不自动点击登录；密码不保存到配置、剪贴板或日志。扫码登录保留，四个账号窗口共用此修复。

设置增加「分享当前版本 1.0.10」，分享内容来自手机实际安装的 APK，文件名带版本号；不使用下载缓存里的历史安装包，也不包含账号、API Key 或聊天数据。接收人仍需自行安装。

完整包同步用户最终验收的十种参考：日常、开心、温柔、害羞、认真、失落、生气、害怕、担心、惊讶。八种采用用户裁剪素材，担心采用验收版 C，失落采用最终验收版 E；按用户最终要求保留各自时长，不再强制十秒。此资源是参考克隆素材，不是新训练权重。已有用户选中的自定义参考保留。

回复与群聊中新增「主动找主人聊天」。默认关闭，保留用户设置；仅向当前配置的大号发私聊。开启后，结合带日期的近期对话和当地时间判断是否值得开场，优先接住未完话题，也可以分享与兴趣有关的一句话，饭点不固定询问吃饭。三天以前的话题降低新鲜度分数，不把旧场景当成现在；近一天重复的问饭、休息和近似开场会被过滤。

从最近一次实际对话结束后计算空闲，受最小联系间隔、选定每日上限、免打扰和开机缓冲限制。「不要主动找我」暂缓二十四小时，明确允许可提前解除。生成被跳过或失败后，按三十分钟与当前设置间隔的较小值冷却，连续不合适逐步延长但不超过设置间隔，不消耗发送次数；有限次数模式每天最多考虑生成上限的两倍。

主人新消息优先，尚未投递的主动开场会取消；切换主人、账号或关闭功能同样失效。主动开场只记作助手消息，不能成为虚构的主人发言、偏好证据或训练问答对；调度文件仅保存元数据与去重指纹，话题证据来自主人真实聊天。

登录输入、分享与声音导入的既有真机验收保留。主动聊天新增离线调度与生产队列回归，使用假 QQ 和假模型，验证未回复后仍可择机再次发起、低分零模型调用、免打扰、切号、新消息优先、跳过后冷却、重复开场与加密记忆。构建及本次设备覆盖核验记录随交付保存；不为测试发送真实 QQ 消息或调用收费模型，不能以模拟检查声称实际主动消息已送达。
