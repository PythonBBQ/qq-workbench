# 七丘 QQ 工作台 0.1.20 预览版

侧栏精简为聊天、模型、酒馆、能力、设置五个入口。酒馆统一管理人设、记忆、养成及上下文；联网、视频、语音、表情和动态放在能力页，长说明按需展开。打开软件自动初始化，填写模型 API Key、大号 QQ 并登录 QQ 后使用。新安装包不预填任何人的 QQ 号。

- QQ 空间说说：主人可生成草稿或直接给出正文发布；可选定时自动发公开主题，默认关闭，默认好友可见、每天最多一条、北京时间 9–22 时运行。发布结果不确定时暂停，不重试旧动态，不使用私人聊天生成公开说说。
- QQ 收藏表情：直接读取小号的收藏，备注含义后按语境选用；主人可随图说“收藏这个表情”。可选自动收藏表情消息，普通照片不会自动收藏。
- 语音：微软 Azure 的晓晓、晓伊、曉臻、曉曼、七海、善熙女声及语速、音高调节，需要单独的 Azure Speech Key；也可选择 QQ 群内置音色。语音生成失败回退文字，长回复不转语音。不包含音色权重训练或真人克隆。
- 真实大号独占操作：发说说、收藏表情、语音朗读、调整音色/语速/音高、开启相关功能和检查更新。群聊需直接 @deepseek；其他账号聊天不会获得这些管理能力。
- 软件内更新：从本仓库 Releases 检查、下载和发起覆盖安装，校验包名、版本、同签名及可用的哈希。安卓安装确认仍需在设备完成。以后每个更新版本均须由维护者构建并发布，软件不会自行改代码。

可用指令示例：私聊主人直接发送，群聊在前面加 `@deepseek`。

```text
写条说说：今天想吃白饭
把这条草稿发出去
发条说说：今天也要认真吃饭。
开启自动说说
收藏这个表情
语音：主人，今天也要好好吃饭。
音色：七海
语速：-10%
音高：10%
检查更新
```
