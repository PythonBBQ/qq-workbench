# 服务、数据与更新边界

1.0.8 将备份、导入、环境重检、缓存清理和安装交接收敛到 `Maintenance`。它持有应用私有文件锁、持久任务类型和恢复意图；`DataMigration.busy` 只供当前进程的界面快速判断，不能独自证明服务或文件已经停止。

维护先记录原运行意图，再停止 RuntimeService，等启动线程与容器退出，最后实际尝试获取 Linux flock。锁文件不删除。只有当前 Android UID、精确 rootfs 路径的 proot 及其后代可被清理；PID 与进程出生时间共同核对，避免误杀复用的 PID 或其他 QQ。

RuntimeService 在退出核验完成前保持 stopping；启动线程使用局部 Process 引用，避免退出线程将共享引用置空。新会话 flock 使用 --close，子进程不继承运行锁。会话脚本对直接子进程执行有界 TERM/等待/KILL/回收。HTTP 停止不响应、初始化尚未启动 Node 和接管旧会话都走同一停止检查。

`PortableDataAccess` 协调主进程与独立 :speech 进程。语音任务持共享文件锁，维护取得独占锁后才导出或替换数据。已有语音未结束时会等待或明确失败；不在后台静默替换正在读取的参考音色。`MaintenanceService` 保持用户发起维护的前台通知和有时限 CPU 唤醒锁，避免 QQ 服务停止后维护失去前台生命周期。

导出先写私有暂存，完成加密才写入用户选择的文档。导入在停止 QQ 前完成密码、文件哈希、路径和设置结构校验；提交前保留目标加密备份，逐单元记录原数据，失败或进程中断通过事务恢复。恢复本身也先停止旧会话并取得独占锁，不能由 RuntimeService 在活动会话旁边直接执行。临时文件仅按固定迁移命名清理。

更新下载不停止 QQ，Activity 消失也由下载前台服务保留进度。重建目标 APK 后仍核对 SHA-256、包名、递增内部版本和签名。进入系统安装前才走 Maintenance 停止会话并持久交接；取消安装恢复原运行意图，包文件保留。系统安装确认仍属于系统。补丁按已安装 APK 的真实 SHA-256 选择；没有适配补丁时可选择整包，不猜同版本 APK 的内容。清单包含公开资源 API ID，API 403 时读到备用清单后仍可切换下载线路；请求公开下载入口时刷新缓存键，避免重复命中过期签名跳转。

卸载/回退属于系统包管理操作，不伪装成清缓存。电脑工具默认只读检查每个用户的记录。同签名旧版用保留数据降级，完整卸载必须显式指定动作，先保存所有已使用空间的可读数据，不能读取或不能确认的空间会阻止卸载。不会删除整个系统分身，也不会承诺恢复已被系统删除的数据。

## 检查

`tools/test-maintenance.py` 编译生产代码并跑主机回归；Windows 无符号链接权限时明确跳过该一项，安卓 instrumentation 必须补测。`tests/BackupInstrumentation.java` 在真实应用上下文、真实 Keystore、真实容器和真实 flock 下运行，测试包独立于生产 APK，不提供生产调试入口。包含合成的多账号记忆/凭据、保存失败回滚，以及真实数据只读导出到隔离目标。测试不向 QQ 发消息。

`tools/build-maintenance-release.py` 用官方已校验 1.0.7 APK 保留大型上游资源，重新编译完整维护源码及 Manifest，更新变化的脚本，重新签名并逐文件核对未改资源。构建记录列出差异；音色资源与模型保持 1.0.7。完整上游构建入口仍为 build.py。
