# 1.0.8 本地语气修复候选

## 问题与改动

用户反馈软绵暧昧和害羞时声音变调、发假，不像已选定的 1.0.7 音色。
检查发现暧昧会按 soft 标签切换到旧轻声参考；害羞试听与聊天的
deliveryStyle 也可能不同。参考录音变化可能影响音色与空间感，
不能仅凭代码检查断言它是全部听感问题的原因。

- 保留 1.0.7 模型与音色资源，不替换模型，不声称重新训练权重。
- 害羞、暧昧请求固定当前语气的主参考，不自动轮换旧轻声备选。
- 统一试听和聊天的参考选择；明确指定 referenceVariant 的诊断对照仍可使用。
- 暧昧语速偏移从 -5 改为 -3，害羞仍为 -5；保留用户手动语速、音调设置。
- ZipVoice 不新增自动变调；原配置音调为 0。
- 提示词区分亲近暧昧与困倦、安慰、夸张撒娇，害羞不要求结巴或幼态表达。
