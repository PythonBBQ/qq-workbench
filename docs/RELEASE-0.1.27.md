# 七丘 QQ 工作台 0.1.27：设备工具、Token 用量与自然聊天

新增主人专用设备操作，经 Shizuku 提供本机 Android Shell 能力。可查型号、电量、存储、第三方应用和屏幕尺寸，可打开应用、调整亮度和媒体音量、按键、按坐标点击及滑动。例：“查看手机电量”“打开B站”“把亮度调到50%”“返回桌面”“adb shell: input tap 300 600”。群聊需 @deepseek。当前真实大号及设备开关会在执行前重新核对，修改大号后旧号码立即失效。

首次到设置→设备权限，安装并启动官方 Shizuku，再授予工作台使用权限并开启设备工具。Shizuku 管理器不捆绑在本 APK 内，系统授权仍需用户操作；手机重启后可能需要重新启动 Shizuku。工作台集成其固定版本 API。明确命令本机解析，复杂的明确设备请求最多一次模型规划、三个动作；参数全部验证后才执行。此版不含自主读屏、猜坐标、任意 Shell 脚本或完整无线 ADB 配对客户端。超时、断连或账号切换立即停止后续动作，已处理动作持久去重，不自动重试点击。

新增设置→Token用量，显示今日、本次运行、保留记录累计、最近调用，以及按模型、站点和用途汇总。大号可在 QQ 发送“查看Token用量”，查询本身不调用模型。聊天、看图/视频、搜索规划、记忆压缩、性格观察、表情备注、空间文案、设备规划和连接测试均计入。只记录服务商报告的用量；缺失或失败请求标明未报告，不能视为零费用。缓存命中已包含在输入，推理Token属于输出明细。保留最近90天、最多2000条；不记录密钥、聊天正文或模型回答，旧版本消耗无法补算，费用以平台账单为准。

酒馆新增自然接话开关、口语自然度及情绪表现力。根据当前话题接话，减少模板开头、重复口头禅和连续反问，与已有角色、记忆及养成配合。不新增模型调用，但风格提示会占用少量输入Token；关闭自然接话即可不注入这段提示。角色表达不改变真实身份、能力或执行结果。

保留 SnowLuma 1.14.22 与官方 Linux QQ 的当前组合、原账号、API卡、表情、空间、聊天和酒馆设置。可同签名覆盖更新，无需卸载或清空数据。
