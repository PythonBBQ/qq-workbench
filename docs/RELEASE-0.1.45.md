# 0.1.45开发记录 · 已合入1.0.0

本版只构建和设备验证，发布草稿已撤下，没有公开APK；以下为开发时的记录。请下载1.0.0。

同一份安装包在不同手机上能否启动，还取决于本机加密凭据与依赖状态。已核对：此前手机安装的0.1.44与GitHub下载包SHA256完全相同，并非发布了不同的软件。0.1.44隔离失效加密项；本版继续减少首次启动对网络下载的依赖。

- 内置252个经Ubuntu APT索引核验的ARM64基础组件。首次按依赖顺序离线安装Python、QQ图形与登录环境；实际复检通过后再继续启动。保留已有账号和配置，不降级较新的系统包。内置恢复仍未完成时才尝试联网补齐；初始化期间不再误报后台健康检查失败。视频FFmpeg组件仍按需联网准备。
- API、角色方案、独立QQ账号及上下文方案统一为卡片视图，展示摘要和当前状态。点角色或上下文卡片应用，点API卡片测试后启用；编辑、删除单独放置。API测试会消耗少量Token。
- 视频采样可选每秒1、2、4帧，默认1帧。QQ、B站与本机视频统一使用所选密度，保留小数秒标记及末尾画面；音轨转写按当前视频段对齐，不重复转写音轨。
- 每次最多15张低清拼图，1/2/4帧分别按120/60/30秒分段；10分钟分别为5/10/20段再汇总。高采样增加模型请求及总Token，10万Token仅为单次规划上限，不是整个视频的保证用量或服务商精确计费。
- 每轮明确告诉模型当前语音通道及引擎；本条文字回复不再被当成没有语音能力。最近同会话的语音受理或合成失败会准确带入，不多调用一次模型。QQ专用群音色不会在私聊中误触发。

安装：Android11+、ARM64，直接覆盖更新，内部版本号46、原签名；无需卸载或清空数据。APK约915MB，含离线依赖，首次仍需解包、配置和足够空间；QQ登录需要网络与本人完成官方验证。旧版若无法软件内更新，请从本页直接下载APK。

验证：207项Node回归、5项组件检查、6项安装故障模拟、5项离线包完整性/版本策略检查及10项Android框架检查通过。OPPO实际FFmpeg验证每秒1/2/4帧及末尾覆盖；10分钟各密度的分批与声音时间对齐另以合成数据验证。小米平板2410CRP4CC的独立空白容器完成252个内置组件离线安装，9项实际环境检查全部通过，dpkg状态审计为空，没有触发联网补齐；耗时约11分钟，首次仍需耐心等待。没有用真实聊天或付费模型作为测试流量。

本版已保留数据覆盖安装到平板，安装APK与待发布APK哈希一致；9项环境检查通过，本机助手启动，QQ登录网页返回HTTP200。平板锁屏，卡片界面的人工观感与该版真实QQ聊天尚未验收；不把程序检查等同于实际收到回复。

更新：发布前校验签名、对齐和全部APK资产，远端APK与SHA256SUMS完整后才公开；正式发布改为1.0.0与0.1.44两个发行版，源码和标签历史保留。默认更新源为 https://api.github.com/repos/PythonBBQ/qq-workbench/releases/latest 。
