# 七丘 QQ 工作台 0.1.26：QQ 空间发布修复

主人私聊可以直接说“发条说说”“发个QQ空间动态”，按公开主题生成为一条说说并发到小号空间；“发条说说：正文”发布指定文字。“写条说说：主题”只生成草稿，“发布草稿”发布已有草稿。群聊仍需 @deepseek。普通用户、引用示例、否定语句不获得发布权限。

空间使用 SnowLuma 获取当前小号登录凭据，HTTPS 改走安卓原生网络。优先使用 user.qzone.qq.com 网关，只读检查失败时才尝试 h5.qzone.qq.com。空空间返回 code=0、total=0、msglist=null 且登录账号一致时视为有效空列表；其他异常结构仍拒绝。发布沿用通过检查的入口，仅发送一次，不在失败后切换入口重复发布。

发布前先只读检查连接。检查失败不发送正文、不消耗每日发布次数，保留草稿并显示原因；自动任务按原设置间隔退避，不每分钟重复生成。实际发布进入结果不确定状态后仍暂停，不自动重发。界面增加“检查QQ空间连接”，主人也可发送“检查QQ空间”。连接成功不等于已验证发布权限，实际成功仍须腾讯返回 tid 发布凭据。

空间凭据只允许发往两个明确的腾讯 HTTPS 网关和固定的读取/发布路径，禁止跳转；模型接口不接收空间凭据。生成说说只使用公开主题和角色语气，不读取私人聊天。原账号、密钥、收藏和备注保留。

验证：111项Node测试通过，包括真实请求形状的模拟、空列表兼容、读入口切换、单次写入、主人权限、指定正文及公开主题生成。6项安卓框架检查通过，另完成同签名APK构建与平板覆盖安装。已在原小米Android15平板覆盖安装0.1.26 / versionCode27，QQ恢复在线；实际小号空间只读检查通过，首次耗时23.13秒；本次不代发测试动态，实际发布收据未进行真实外发验收。
