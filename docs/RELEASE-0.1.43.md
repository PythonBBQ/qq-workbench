# 0.1.43 · QQ 登录就绪检测与环境修复

修复刚打开 QQ 登录页就出现 `ERR_CONNECTION_REFUSED` 的问题。窗口会先等待本机网页和桌面服务就绪，再加载 QQ；准备中、失败及重试状态直接显示，切换账号后旧请求不会打开另一账号的窗口。

- 每次启动检查 Python、websockify、noVNC、虚拟显示器、桌面会话、Linux QQ、运行库及 SnowLuma Node，不再仅相信旧的安装完成标记。
- 缺失的内置 Python 和 QQ 文件优先从 APK 恢复，其余组件从系统软件源补齐后复检。网络、空间和软件包锁错误单独提示。
- 诊断页新增逐项检查与“自动补齐并重新启动”；先等待原会话退出，避免重复启动 QQ。保留账号、聊天、模型设置和人设。

安装：Android 11+、ARM64；首次准备需要联网和数 GB 空间。已有版本直接覆盖更新，不先卸载。内部版本号44，沿用原签名。
