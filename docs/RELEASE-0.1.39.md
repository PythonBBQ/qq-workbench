# 七丘 QQ 工作台 0.1.39：分层记忆、省上下文与电脑 Codex 接入

在0.1.38的本机常提词加权上加入事件时间线，与近期对话、明确偏好分开。原有角色、账号、群聊和发言人隔离保持。不会安装第三方记忆服务，不新增模型、嵌入或向量数据库调用；仍是本机词法召回，不是完整语义记忆框架。

明确自述的计划或进展，例如“我明天去医院复查”，以及“记住：医院复查改到周五”，会保存用户原话、记录时间和当时设备时区。明显引用、假设、问题、提醒请求和凭据类内容不自动提取。喜好仍归入偏好层，不把“我喜欢周末吃白饭”当作日程。“记录时间”不是事件发生时间；模型获得明确说明，明天/下周相对当时日期理解、最新纠正优先、旧计划不代表仍有效。用户自述的完成不冒充助手已执行，也不据此创建提醒。

每会话最多64条事件，重启与近期120轮溢出后可保留；同一天相同原话合并。只有与当前问题相关或明确追问旧安排时才召回，最多4条、600字符。事件从原有旧记忆预算中分配空间：有事件时旧摘要与摘录控制在1200字符，明确偏好按问题相关性筛选，常驻说话要求保留，常规最多4条，明确回忆最多6条、1600字符。不把整份时间线发给模型，计数/整理不额外调用模型，但发给聊天模型的记忆文字照常计入输入Token，不承诺零Token聊天或固定节省比例。

酒馆→记忆可关闭事件采集与注入，逐条查看记录时间、时区和原话，也可删除单条事件。结束当前聊天清近期对话与词频，保留长期事件和明确偏好；清空上下文同时清事件、词频和摘要、保留明确偏好；删除整个会话或账号记忆按原规则全部删除。旧版本记忆兼容，不扫描旧聊天反推事件，不清空原偏好。

验证：175项Node回归、3项电脑执行端隔离测试和7项Android框架检查通过，涵盖分类、引用/问题过滤、跨时区标记、历史溢出、加密重载、时序纠正、上限与预算、逐条删除的鉴权和偏好保留、旧文件迁移。测试不调用付费模型或发送QQ消息。沿用原签名覆盖更新。


## 上下文与提示词

近期对话已经携带的同一句偏好/事件不再重复注入记忆层；旧摘录与选中的明确记忆去重。具体新话题只选相关的模型摘要原文片段，短追问、代词承接及明确回忆保留摘要背景。世界书同一条背景去重，不改原始聊天和长期记忆文件。视频、QQ空间、设备操作等说明按本轮话题加入，闲聊不携带整套用法；身份核验、实际工具证据、低可信资料边界始终保留。

这些筛选都在本机，不额外请求模型。选择的记忆、近期对话和提示词仍计输入Token；可选模型压缩/性格观察保持原开关，不承诺固定节省比例。

## @codex 电脑执行端

只有当前大号明确@codex才派发任务，中文可以紧贴标记；两种标记同时出现按第一个选择，邮箱和相似名称不触发。普通聊天仍交所选聊天模型，电脑任务独立串行运行，不阻塞聊天。完成/缺信息/失败的真实状态与文字验证回到原私聊或群聊，并以@deepseek标记交回聊天上下文；这里直接回传Codex验收文字，不额外调用DeepSeek整理。该任务不是Codex桌面当前聊天的同一会话。

电脑运行tools/android-codex-worker.py，显式指定设备和工作站目录。采用ADB到设备回环端口的转发，读取同一应用进程的本机鉴权，仅保存在电脑内存，不开放公网、不上传本机凭据。执行端沿用电脑现有Codex服务商和模型配置，使用workspace-write及自动审核，不绕过沙箱。普通联系人不能派发；切换大号/账号/角色后旧结果不跨身份投递。

接单、执行结果和QQ回执分开：重复QQ事件不会重复运行，结果确认丢失只重试本机幂等回传，不重跑任务；QQ发送未确认不重发。运行中断的任务不自动重做，排队超过15分钟取消。电脑、设备ADB连接及应用本地服务必须在线；离线时明确说明任务未开始。电脑待机/关机或拔掉USB后仍可与DeepSeek聊天，但电脑任务不可执行。无线ADB须已经配对且网络可达。

电脑执行端返回的usage单独按codex用途加入用量；服务商未返回完整用量不视为零。真实、不使用工具的Codex连通探测与结构化验收返回已成功；回归测试用模拟电脑与QQ，不等于用户已收到真实QQ回复。

平板安装验证：已核对0.1.39与安装包模块哈希，真实QQ在线、自动回复开启、电脑执行端在线；设备隔离验证覆盖分层事件、加密重载、相关召回、结束保留与清空行为，不读取真实记忆、不调用模型、不发送QQ。真实用户@codex消息收发仍待用户现场验证。
