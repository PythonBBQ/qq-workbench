# 七丘 QQ 工作台 1.0.9（本地更新）

内部版本 10015，同签名覆盖安装，保留原账号、模型卡片、记忆和 1.0.7 音色预设。本次不发布 GitHub，提供完整 APK 与适用于精确底包的小补丁。

## 更新内容

- 指定网页阅读：直接提供网址，读取公开正文，追问沿用本次会话中相应的网页。
- 网页视频：发现网页声明的视频文件或内嵌 B站播放器，沿用现有抽帧、音轨转写、上下文回答和来源回查。每次最多一个视频，32 MiB、10 分钟，支持每秒 1/2/4 帧，需要视觉模型；不支持 HLS/DASH、需要播放器脚本或权限验证的任意站点。
- 连接状态：区分组件启动、等待 QQ 登录和接入长时间未就绪；首页及登录窗口显示真实阶段，断线时不再只显示“自动回复已开启”。
- 同类恢复提示限频，避免淹没最近对话；保留严格账号及在线核验，不自动重发结果不确定的消息。
