# 七丘 QQ 工作台 0.1.37：英文与中英混说音轨

将原来的中文专用音轨模型替换为本机多语种SenseVoice int8模型，自动识别中文、英文及中英混说；模型也支持日语、韩语、粤语。继续使用现有Sherpa-ONNX CPU运行时，最多2线程，不上传音频，不增加收费识别API调用。首次更新会替换旧模型；不重复保留两套模型权重。压缩安装包会因模型扩大而增加体积。

针对“man”一类短英文可能被转成重复中文谐音的问题，可疑的连续中文重复会标记为不确定，并对相应分段尝试一次英文重听，每个视频最多3段。原始转写保留，英文结果仅是候选，不能靠关键词把“美美美”强行改成“man”，也不能据此认定具体人物或梗。英文重听失败时保留原文，不使整段视频失败。每30秒原文和候选合计仍不超过300字，每两分钟1200字、十分钟6000字的转写文字预算保持。

默认只结合画面和识别出的对白文字回答；只有当前用户明确问声音、音乐或BGM才分析音轨，不主动介绍或发送BGM。原始媒体流不加载播放器弹幕，空转写不能判断静音，音轨分类概率不能充当精确识曲。

验证：159项Node回归和7项Android框架检查通过。平板隔离运行新版转写，发布者英文、中文及拼接混说样本均返回相应语言文字，每例约4—5秒。系统英文声音合成的短句“Man, man, man, what can I say?”本机约4秒完整保留英文，未变成“美美美”；这不是用户原梗音频的验证。英文个别词及混说衔接处仍有误识别，不能视为精确字幕；变速、重混、音乐覆盖下的短促梗音频仍可能识别不准。测试不调用付费模型或发送QQ消息。

模型来源、发布资产SHA256、原作者与FunASR模型许可完整随包保留；模型许可与Sherpa运行时代码许可分别列明。沿用原签名，覆盖更新保留QQ账号、API、B站登录、人设和聊天设置。
