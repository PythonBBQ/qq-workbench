## 已复现并修复

| 问题 | 触发方式与修复 |
| --- | --- |
| 长语音突然回退文字 | 分段将小尾句重新合并到超过本机 240 字符的长度；补充平面汉字还存在 Java/JavaScript 字符计数差异。按 Java UTF-16 长度同时约束分段与尾句合并，保留全部原文和字符边界。 |
| 关闭情绪仍沿用旧参数 | 固定害羞或模型返回 shy 时，虽然发送给原生的 mood 是 neutral，推理步数和固定参考标志仍按旧情绪计算。现在先归一化情绪，再计算参考、步数和语速。手动音调设置继续保留。 |
| 试听与聊天不同 | 普通试听未明确 deliveryStyle，导致“晚安”之类文字触发原生自己的备选参考；轻声文字、系统 TTS 情绪偏移与自然断句开关也与聊天不同。试听现在明确传递相同选择规则与参数。 |
| 取消解析触发未处理异常 | 已取消的请求仍启动 Python，在环境缺失时尚未注册子进程错误处理就返回。改为启动前检查取消状态，并先注册错误处理，再处理取消竞态。 |
| 更新错误页破坏续传 | API/代理返回 HTTP 200 的 JSON 或 HTML 时，会被当作包体写入，覆盖已有正确片段。检测到网页/JSON 响应后，在写文件前切换官方通道，保持原续传位置，最终仍核对 SHA-256。 |

所有新增回归均在修复前运行并失败，修复后通过。试听具体自然度、
音色还原度属于听感评价，本轮逻辑测试不证明这些主观质量已经改善。
