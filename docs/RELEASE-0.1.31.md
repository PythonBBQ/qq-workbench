# 七丘 QQ 工作台 0.1.31：多平台分享解析与每秒视频画面

以新的多平台解析入口替换原来的“读取网页／读取B站”分立入口。QQ私聊、已唤起的群聊收到链接或JSON/XML分享卡片后，读取作品标题、正文/简介和可用配图，交给当前模型结合聊天上下文回应。直接链接不增加一次总结或意图规划模型调用；网页搜索、B站搜索和原资料笔记保留。

APK内置Qfxaile/astrbot_plugin_multi_parser v1.3.0的MIT平台解析核心，固定提交b40468057e11a3e6301e93453285a1b898da522c，保留许可；不安装另一套AstrBot运行时。包括B站、抖音、小红书、微博、知乎、贴吧、微信公众号/视频号、小黑盒、GitHub仓库、番茄小说、腾讯频道卡片、QQ空间公开分享，以及默认关闭的Pixiv。不同平台支持的链接种类不同，不能保证登录受限或接口变动后的内容可读。番茄小说只读取作品信息，不下载章节。

每次最多读取两张配图，沿用API卡片的视觉配置；无视觉模型或图片下载失败时只处理文字并明确说明。不会将视频封面当成完整视频，不自动下载整段视频或音轨。QQ发送的视频与本机导入视频均沿用视频画面理解。

可选平台Cookie由安卓密钥库加密保存在本机，只交给对应平台解析器；不要求填写QQ Cookie，不向模型发送平台Cookie或原始分享卡片中的令牌和用户标识。平台登录资料入口折叠在联网页内。维持真实主人权限、群聊触发规则、首次协议确认、原账号、API卡片和聊天数据。解析文字只注入当前请求，不反复携带为对话历史；相关本机笔记仍按既有预算检索。

解析组件及8个纯Python依赖随APK离线打包，不需要用户安装AstrBot或手动安装pip依赖；固定依赖下载哈希与许可一并保存。整个解析25秒、最多12次受限平台请求，单个响应最多4MB；图片每张最多3MB。失败不冒充读取成功。


视频改为每秒取1帧，画面等比缩至256×144以内并加黑边，每8帧按4列2行组成1024×288低清JPEG拼图，提示中逐格标记真实采样秒数。10分钟以内的完整时段都读取：2分钟120帧、15张拼图；10分钟600帧、75张拼图，分5段依次分析后再按时间顺序汇总。每次视觉请求最多15张低清图、文字最多24000字符，按每图3000Token加文字字符数及输出预留估算，以每2分钟10万Token为规划上限；不同模型和中转站的实际图像计费可能不同，不能作为硬性账单保证。服务商返回用量时显示本次所有分段及汇总调用的输入/输出总量；缺失任意调用用量时明确显示未完整返回，不记为零。

视频限制仍为32MB、10分钟以内；没有丢弃两分钟之后的内容。每段失败即停止，不将部分结果冒充完整视频。每秒采样仍不是逐帧观看，不听音轨、不识别完整字幕，快速动作与小字可能遗漏。后续对话保留文字分析，不重复发送视频拼图。解码使用单次顺序FFmpeg调用，临时拼图始终清理，最多一张原生拼图驻留绘制内存；解析分享链接只读取分享内容，不会将封面冒充完整视频。

真机合成视频验证：平板FFmpeg解码2分钟视频得到120帧、15张图、547820字节JPEG，约3.62秒；10分钟得到600帧、75张图、2750623字节JPEG，约10.19秒。同时覆盖1.1秒和121.1秒非整段边界；每秒时间标记从0覆盖至119/599，无缺帧或临时文件残留；每段规划估算约4.72万Token，这些是合成低分辨率视频的本地解码与预算验证，未调用付费视觉模型，不代表所有真实视频的速度和实际Token账单。

验证：135项Node回归通过，覆盖真实打包解析器的B站、公众号、小红书和GitHub内容提取、QQ分享卡片到模型/图片的完整模拟聊天路由、凭据隔离、失败和缓存；7项安卓框架检查通过；独立shell媒体诊断仍被系统以137终止，不计为原生媒体解码通过，视频兼容路径由上述平板容器实测覆盖。APK原签名、对齐和资产哈希通过。本次未发送真实QQ测试消息或发布空间动态。已在小米Android15平板覆盖安装，并在正式应用界面实测公开GitHub仓库分享解析成功，显示真实标题、简介、来源与资料范围，未保存测试笔记。独立app_process诊断在发起读取后被系统以137终止，未计为通过；改由应用内实际操作验收。原QQ连接核验在线。
