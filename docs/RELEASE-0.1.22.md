# 七丘 QQ 工作台 0.1.22：主人说一声就能收藏表情

主人可随表情说“收藏这个”“存一下这个表情”，也可先发表情，5分钟内再说“收藏一下”“把刚才的表情收藏起来”。私聊和群聊均支持；此项明确收藏请求无需额外 @deepseek。只识别当前设置中的真实主人 QQ，昵称、人设及其他账号的请求不会授予收藏权限。

只使用当前聊天里主人发送的图片，按账号、主人、群聊/私聊分别记录短期引用。引用回复可指定主人先前发的图片；过期、跨群、非主人图片或多图不明确时会提示重发。更换主人、QQ账号或断开连接后清除短期引用，排队时固定所选图片，避免后续消息替换收藏目标。

移除“自动收藏收到的表情包”开关和后台逻辑，旧设置即使开启也不会收集其他人的表情；仍可让模型按语境使用小号现有 QQ 收藏。收藏判断在本地完成，不额外调用模型。不重复收藏同一图片，QQ结果未确认时不自动重试。
